# 实验清单 · 第 12 章 报错与调试

- 项目：修 bug 闯关
- 脚本：`code/ch12/buggy.py`（故意出错）、`code/ch12/fixed.py`（修好）
- 实测时间：2026-11-03 16:41 CST（北京时间）

## 1. 跑坏程序（期望报错，exit 1）
```bash
printf '9\n' | python3 code/ch12/buggy.py
```
```
你几岁？ Traceback (most recent call last):
  File "/workspace/books/kids-python/code/ch12/buggy.py", line 3, in <module>
    next_year = age + 1
                ~~~~^~~
TypeError: can only concatenate str (not "int") to str
[exit 1]
```

**报错原文**：`TypeError: can only concatenate str (not "int") to str`（第 3 行 `next_year = age + 1`）

**原因**：`input` 返回文字，文字不能和数字 1 相加。

**修法**：第 2 行改成 `age = int(input("你几岁？ "))`。

## 2. 跑修好的程序（期望 exit 0）
```bash
printf '9\n' | python3 code/ch12/fixed.py
```
```
你几岁？ 明年你就 10 岁啦！
[exit 0]
```
