# 小学生相关「计算机 / 编程」等级大纲速查（2026-11-02）

结论先说：国内没有单一全国统考叫「小学生计算机等级考试」。和小学最相关、可对标写书的主要有三套：中国电子学会青少年软件编程（Python）一至六级、CCF GESP Python 一至八级、江苏 YCRE（现常称青少年计算机人工智能素养测评）一至五级（小学主要落在一至三级）。

## 1. 中国电子学会 · 青少年软件编程（Python）

- 性质：行业团体考级，偏「学 Python 编程」
- 级别：一至六级
- 2026 修订要点源：已落盘 PDF `/workspace/research/kids-python-book/青少年软件编程Python等级考试大纲-2026修订.pdf`
- 公开入口示例：[qceit 修订 PDF](https://file.qceit.org.cn/fileroot/resource/46e2700f-35d7-4968-a9cf-c7831fee91e5/%E9%9D%92%E5%B0%91%E5%B9%B4%E8%BD%AF%E4%BB%B6%E7%BC%96%E7%A8%8B%EF%BC%88Python%EF%BC%89%E8%80%83%E7%BA%B2%E4%BF%AE%E8%AE%A2%E5%86%85%E5%AE%B9%EF%BC%882026%E4%BF%AE%E8%AE%A2%EF%BC%89.pdf)

| 等级 | 能力摘要 | 核心知识点 |
| --- | --- | --- |
| 一级 | 环境 + 顺序/单分支简单程序 | 变量与类型转换、简单运算、Turtle、单分支 |
| 二级 | 核心数据类型 + 分支/循环 | 列表、元组、字符串、字典、集合 |
| 三级 | 算法入门 | 推导式、内置函数、枚举/排序、数制转换 |
| 四级 | 函数与模块化 | 自定义函数、递归与分治、查找、标准库 |
| 五级 | 数据处理 | 文件读写、pandas/matplotlib 入门、SQLite |
| 六级 | OOP + 简单数据结构 | 类与对象、数组/队列/栈、二叉树遍历 |

试题结构建议：一至四级客观约 60–70%、编程约 30–40%；五至六级客观约 50–70%、编程约 30–50%。

对写书：小学全段最稳妥对标到 **一至二级必会，三级选学**；递归、数据库、类属于中高段拔高。

## 2. CCF · GESP（编程能力等级认证）Python

- 性质：中国计算机学会认证，覆盖中小学，Python 一至八级
- 已落盘：`/workspace/research/kids-python-book/GESP-C++Python认证标准.pdf`
- 入口：[gesp.ccf.org.cn 认证标准 PDF](https://gesp.ccf.org.cn/101/attach/1579675000242208.pdf)

小学常见可吃到的前几级（摘录）：

| 等级 | Python 侧要点 |
| --- | --- |
| 一级 | 环境与计算机基础、变量、基本类型、顺序/循环/选择、I/O、Turtle |
| 二级 | 存储与网络、流程图、ASCII、类型转换、多层分支/循环、简单数学函数 |
| 三级 | 编码与进制、集合/列表解析、字符串函数、枚举与模拟等算法入门 |
| 四级 | 函数与作用域、复合类型嵌套、递推与排序、文件读写、异常处理 |

对写书：若想「考级友好」，目录最好能显式映射 GESP 一至三级知识点。

## 3. 江苏 YCRE（青少年计算机科学素养 / 现 AI 素养测评）

- 性质：江苏省计算机学会等主办，偏「计算机科学素养」，不全是 Python 考级
- 团体标准：`T/JSCS 0003—2021`，已落盘 `/workspace/research/kids-python-book/YCRE-素养等级划分标准.pdf`
- 官网：[nycre.cn](https://www.nycre.cn/)（样卷页可下一级至五级 2020 版大纲 PDF）

小学相关档：

| 等级 | 适用 | 和编程相关的要点 |
| --- | --- | --- |
| 一级 | 幼儿园中班及以上 | 设备认识、顺序与简单循环、实物/积木编程、网络安全入门 |
| 二级 | 小学 2 年级及以上 | 软硬件与输入输出、二进制初步、变量与数据类型、循环与事件、Scratch 等积木、网络与文件、可视化与安全 |
| 三级 | 小学 4 年级及以上 | 设备互联、位与系统、**开始要求能用 Python 或 C++ 写简单程序**、更完整的算法与系统设计素养 |

对写书：开篇「计算机是什么 / 软硬件 / 安全」可直接借 YCRE 一至二级；正文 Python 主线仍更适合对齐电子学会或 GESP。
