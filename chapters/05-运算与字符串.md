## 概念

- 运算符：`+` 加、`-` 减、`*` 乘、`/` 除、`//` 整除、`%` 余数。
- **整数 `int`**：如 `4`；**小数 `float`**：如 `1.5`。
- `input` 拿到的永远是**文字**，要算数先变身：`int("4")` 得到 4，`float("1.5")` 得到 1.5。
- 数字要和文字拼在一起，先用 `str(数字)` 变回文字。
- `round(数字, 2)` 保留两位小数。

<!-- high -->
`"3" + "4"` 得 `"34"`（拼字），`3 + 4` 得 `7`（算数）。弄混类型是新手最常见的错误，第 12 章会专门练怎么看报错。

## 照着打

照着打，注意 `float` 和 `int` 别漏掉：

```python
# 小卖部计算器
item_name = input("买什么？ ")
price = float(input("单价是多少元？ "))
count = int(input("买几个？ "))
total = price * count
print(item_name + " 一共 " + str(count) + " 个")
print("应付：" + str(round(total, 2)) + " 元")
```
