## 概念

- **数据**：一堆有意义的数字或文字，这里是「名字 → 身高」，用第 10 章的字典装。
- **求和**：循环把每个人的身高加进 `total`。
- **平均数** = 总和 ÷ 人数，`len(heights)` 是人数。
- `max(heights, key=heights.get)`：找身高最大的那个**名字**；`min` 同理找最小。
- **文字柱状图**：`"■" * 26` 会得到 26 个方块，用 `//` 整除决定方块个数。

平均数会被特别高或特别矮的一个人「拉偏」。数学里还有「中位数」：把身高排好队，取正中间那个。可以用 `sorted(heights.values())` 先排序。

## 流程图或伪代码

```
准备 字典 heights：名字 → 身高
total = 0
对 每个名字：total 加上 他的身高
平均 = total ÷ 人数
找出 最高的名字、最矮的名字
打印 人数、平均、最高、最矮
对 每个名字：
    方块个数 = 身高 整除 5
    打印 名字 | 方块 身高
```

## 照着打

照着打，然后把字典换成你们小组的真实身高：

```python
# 班级身高统计图
heights = {"小明": 132, "小红": 128, "小刚": 141, "小美": 125, "小李": 136}

total = 0
for name in heights:
    total = total + heights[name]
average = total / len(heights)

tallest = max(heights, key=heights.get)
shortest = min(heights, key=heights.get)

print("=== 班级身高统计 ===")
print("人数：" + str(len(heights)))
print("平均身高：" + str(round(average, 1)) + " 厘米")
print("最高：" + tallest + " " + str(heights[tallest]) + " 厘米")
print("最矮：" + shortest + " " + str(heights[shortest]) + " 厘米")
print()
print("=== 身高柱状图（每个■代表 5 厘米） ===")
for name in heights:
    bar = "■" * (heights[name] // 5)
    print(name + " | " + bar + " " + str(heights[name]))
```
